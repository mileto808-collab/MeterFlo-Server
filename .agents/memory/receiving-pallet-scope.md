name: Receiving pallet scope
description: Pallets are optional receiving scan groups, separate from trusted serial-file imports.
---
Keep pallets as receiving groups saved with receipt history, not ongoing stock containers that must be tracked through staging, transfers, or installation.

**Why:** The user chose “Receiving groups saved with receipt history.” Workers may scan each meter while breaking down several pallets and need expected-versus-scanned counts to identify which pallet has a missed scan.

**How to apply:** Preserve each group's label, expected count and individual serial membership with receiving evidence. Keep serial-file import as a separate, direct option; the user described these as generally trusted lists, not a process requiring pallet setup. Never infer individual serials from a pallet barcode alone.
