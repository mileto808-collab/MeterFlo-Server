---
name: Work-order print content
description: User requirements for plain work-order printouts and billing-only inventory summaries.
---

Remove colored boxes from work-order printouts. When inventory is enabled, show a concise line-item table including labor. Display billing when set, never internal costs.

**Why:** The user explicitly requested simpler work-order printouts and clarified, “just display billing if set not cost.”

**How to apply:** Keep normal work-order details, equipment, readings, GPS, notes and signatures. Do not turn the printout into a reservation, custody or transaction-history report. Preserve existing billing visibility restrictions. This rule is for work-order printouts, not all inventory reports.
